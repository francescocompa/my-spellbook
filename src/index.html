Import 5etools data

This planner ships without spell data. Load a 5etools data export to fill it with spells, classes, subclasses, feats and species. Everything is parsed and stored in your browser — nothing is uploaded.

Drop the whole 5etools data folder as a .zip (fastest), or individual JSON files. For per-file loads, include generated/gendata-spell-source-lookup.json so spells know which classes can cast them.
